# Roadmap Gaps

| Feature | Current status | Why it is not required for pilot | What would trigger implementation |
| --- | --- | --- | --- |
| Multi-tenancy | Not implemented | Current deployment is single-customer | customer asks for shared runtime or platform mode |
| Billing | Not implemented | Not part of the current delivery | commercial ops require subscription management |
| Self-service provisioning | Not implemented | Too broad for the current pilot scope | larger platform rollout |
| Universal integrations | Not implemented | pilot requires one or two approved sources | new customer requires additional connectors |
| Autonomous sending | Not implemented | outcome safety requires approval gates | expanded operating model or automation policy |
| White-label infrastructure | Not implemented | out of scope for the current delivery | white-label agreement and additional product scope |
| Large analytics suite | Not implemented | current customer value is workflow governance and audit | more advanced reporting and dashboarding needs |

The project should stay within the current pilot scope unless a customer engagement specifically requires a broader product line.
