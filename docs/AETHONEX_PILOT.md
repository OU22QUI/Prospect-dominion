# Aethonex Pilot

## Pilot offer

- proposed price: $4,500, subject to technical review and signed scope
- target duration: 30 days
- proposed scope: one governed CSV-backed outbound workflow
- bounded environment: one customer deployment
- approval gate: human approval required before outbound send
- review cadence: to be agreed in the written scope

## Included

- proposed deployment into a customer-controlled environment after technical and security approval
- environment configuration and validation, as scoped
- workflow implementation for the approved CSV pilot path
- operator guidance and handover, as listed in the signed scope

## Not included

- universal enterprise rollout
- subscription platform
- broad self-service provisioning
- promises of business outcome without a real trial and agreed scope
- customer-data processing before signed data-processing terms and subprocessor review
